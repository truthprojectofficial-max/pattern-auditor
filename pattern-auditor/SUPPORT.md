# Support

This project is a single-operator, local-only build. There is no
helpdesk. There is no support contract. There is no SLA.

## What you can do

- Open a GitHub issue on https://github.com/truthprojectofficial-max/pattern-auditor/issues
- Read the README.md, USER_MANUAL.md, and CHANGELOG.md
- Email truth.project.official@gmail.com for anything sensitive

## What you cannot do

- Expect a reply inside 24 hours. Replies happen when they happen.
- Demand feature work. New patterns are added on the operator's schedule.
- Report that "the app is wrong because my friend told me the text was honest." The app reports lexical pattern matches; it does not adjudicate truth.
