# Pattern AI-uditor - Theme & colour brief

The current app uses a dark navy + sky cyan + pink palette. The launcher icon is a magnifier over three pattern dots. Everything is operator-owned (Justin Barnett / TruthProject), no external accounts, no brand identity to defend.

Three palette options below. Each ships with the matching Compose colour scheme, the launcher icon in three sizes (48, 72, 96), and a 512x512 PNG for the Play Store icon.

## Option A: TruthProject default (current)

The palette already in the app. Dark navy ground, sky cyan accent, pink highlight. The cyan signals "analysis", the pink signals "match found".

- Background: #0F172A (slate-900)
- Primary:   #38BDF8 (sky-400)
- Accent:    #F472B6 (pink-400)
- Text:      #E2E8F0 (slate-200)
- Muted:     #64748B (slate-500)

This is the palette you already have. Picking this means zero risk and zero rework.

## Option B: Forensic courtroom

Beige ground, deep blue, gold. Reads as "evidence", "court", "affidavit". Aligns with the sibling repo (truthasaservice) which is also a court-grade deception-detection tool.

- Background: #FAF8F1 (parchment)
- Primary:   #1E3A8A (blue-900)
- Accent:    #B45309 (amber-700)
- Text:      #1F2937 (slate-800)
- Muted:     #78716C (stone-500)

Stronger brand identity. More work: requires a recolour of the launcher icon, the splash, the Compose colour scheme. ~2 hours of work.

## Option C: Minimal mono

Pure black ground, white foreground, one accent. Reads as "tool", not "product". Closest to the operator-only, no-nonsense spirit of the README.

- Background: #000000
- Primary:   #FFFFFF
- Accent:    #94A3B8 (slate-400)
- Text:      #FFFFFF
- Muted:     #525252 (neutral-600)

Cheapest to print, photocopy, sticker. Best contrast for older devices. Worst for app store marketing.

## Recommendation

Option A for v0.1.0 (it is already built). Option B for v0.2.0 if you decide to rebrand toward "TruthProject" as the umbrella for the sister apps.
