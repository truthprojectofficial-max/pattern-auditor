## 7. Ollama + Android + cmdline-tools 22.0 + Windows 11 notes

These are the things that bit me earlier in this build; I am logging them so the next person doesn't re-learn them:

| Symptom | Cause | Fix |
|---|---|---|
| `gradlew assembleDebug` warning: "SDK XML version 4 was encountered. This version only understands SDK XML versions up to 3." | AGP 8.5.2 reads an SDK that was packaged by a newer cmdline-tools (22.0) than the one it was tested against. | Cosmetic, build still works. Pin cmdline-tools to 19.0 or 20.0 if the warning is annoying. |
| `sdkmanager` shows "WARNING: The SDK Manager CLI tool (sdkmanager) is deprecated. Use Android CLI instead." | Google is migrating to `android sdk` subcommands. | Cosmetic. `sdkmanager` still works. |
| `gradle` not on PATH after a clean Windows install | Gradle is not preinstalled; Chocolatey failed in this sandbox because the lock directory was held. | Downloaded `gradle-8.7-bin.zip` and pointed PATH at it manually. |
| `choco install gradle` failed with "Unable to obtain lock file" | The choco lib lock was held. | Delete the lock file in `C:\ProgramData\chocolatey\lib\` and retry, or just download Gradle directly. |
| `input text "..."` via adb drops spaces and special chars | The shell on the device mangles `%`, spaces, and quotes. | Use `adb shell "input text '...%s...%n...'"` and prefix the whole arg with `adb shell --`. For complex text, push the payload to `/sdcard/` and read it via `sh -c`. |
| Tap on a Compose Button sometimes doesn't fire | The button's bounds reported by `uiautomator` are the outer view, the inner TextView has the visible text. | Tap the centre of the `clickable=true` parent view's bounds, not the centre of the TextView. |
| `aapt2 dump badging` fails with "Failed to load resources table" on a 64K-method APK | Not relevant at our size. | N/A |
